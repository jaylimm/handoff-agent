# handoff-agent

Per-project session handoff notes for GitHub Copilot in VS Code. At the end of a chat, `/handoff-save` writes a short note about where you are; `/handoff-view` shows it any time so you can follow along; in a new chat, `/handoff-resume` reads it back so you continue without re-explaining.

- **One note per project.** Switching projects switches notes; contexts never mix.
- **Always fresh.** Every save rebuilds the note from the current state, so old decisions don't pile up. The previous version is kept as a `.prev.md` backup.
- **You review before saving.** The draft is shown in chat; nothing is saved until you approve.
- **Repo-checked.** Each note records its repo root, branch, last commit and uncommitted files. Resume refuses a note from a different repo and points out what changed since.

## Install

Requires VS Code with GitHub Copilot Chat, `chat.plugins.enabled` turned on, and Windows PowerShell 5.1 or PowerShell 7. `git` is optional.

**From GitHub** (after this repo is pushed):
1. Command Palette → **Chat: Install Plugin from Source**.
2. Enter the repo URL, for example `https://github.com/<you>/handoff-agent`, and choose **User**.

**From a local folder:** same command, but enter the folder path, for example `C:\Users\<you>\handoff-agent`.

**Manual fallback:** copy `skills\handoff-save`, `skills\handoff-resume` and `skills\handoff-view` into `%USERPROFILE%\.copilot\skills\`. This gives you the three commands without the Handoff agent.

Start a new chat afterwards; skills are loaded when a session starts.

## Use

| You type | What happens |
|---|---|
| `/handoff-save` | Drafts a fresh note from this chat, shows it to you, saves after you approve. |
| `/handoff-save edit: remove the prune decision` | Changes only what you ask in the saved note, shows it, saves after you approve. |
| `/handoff-view` | Shows this project's saved note as-is (read-only) so you can read and follow it. |
| `/handoff-view previous` | Shows the `.prev.md` backup instead. |
| `/handoff-resume` | Checks the note belongs to this repo, compares it with git, summarizes, then asks before continuing. |
| Handoff agent: "list my handoff notes" | Lists every saved note and its project. |

## The note

Saved as `%USERPROFILE%\.copilot\handoffs\<folder>-<hash>.md` (set `HANDOFF_DIR` to use another folder). The hash comes from the repo path, so two folders with the same name keep separate notes. Notes live outside your repos and are never committed.

The header (repo, branch, commit, uncommitted files, time) is generated by the script. The body has fixed sections, at most 80 lines:

```markdown
## Objective & Status
## Modified Files & Key Changes
## Verified Facts & Decisions
## Tried & Failed
## Waiting on You
## Next Steps
## Don't Do
```
